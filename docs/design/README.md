## 03 机构后台：赛事运营

概念展示多赛事、待办、今日比赛、套餐及交付入口。真实Web已具备赛事草稿、球队、报名审核／冻结，以及2–32队单循环生成、共享场地和时间安排、冲突定位、确认发布与只读历史。当前不支持分组／淘汰、自动优化或发布后改期；套餐、赞助和赛后交付仍为规划，概念图示例比分与真实记分数据无关，不能作为真实比赛事实。

P04-A实际界面记录见[草稿与正式赛程视觉证据](../evidence/P04-A/README.md)，维持深蓝／橙色风格及桌面、390宽度可用性。这些截图使用合成HTTP数据；真实业务验收另见[P04-A任务](../tasks/P04-A.md)和[CI39737812114](https://github.com/xyq-dev/small-city-basketball/actions/runs/39737812114)。这些P04截图本身不证明记分或确认能力，P05-A实际交付边界见下节；没有生产部署，OBS仍未接入。
