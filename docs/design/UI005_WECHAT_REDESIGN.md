# UI005 小程序前端视觉重设计

日期：2026-11-03 Asia/Shanghai。代码基线：`ef62cb1d47b3b63d9c854043f07cb5f8d6503b52`。

用户本轮明确要求根据 GitHub 功能重新设计并实现小程序前端；本稿替代本轮修改页面的旧视觉约束，不改变业务合同。交付以实际 WXML/WXSS 渲染为准，不以概念效果图替代。

## 设计与交互

- 定位：全国赛事发现、同城篮球服务、球队协作、个人参与；品牌“让热爱，有主场”。保留首页、赛事、同城、球队、我的五导航。
- 视觉：运动杂志的信息层次，深蓝文字、暖橙行动、白色卡片和浅灰底。深蓝 `#123c73`、强调橙 `#f28c28`、正文 `#18283f`、次级 `#63758b`、画布 `#f4f6fa`。不堆叠大海报、渐变和立体图标。
- 间距：页面左右 16px；区块间 24px；卡片内 16px；元素 8/12px。卡片圆角 18px，输入 12px，按钮 12px；细描边代替厚重阴影。
- 字体：中文系统字体；页面标题 26/34、区块 18/28、正文 14/22、辅助 12/18；长名称换行，数字用等宽数字。点击目标最小 44px。
- 主页面共用真实状态栏/胶囊安全区，搜索工具行明确；底栏固定、安全区留白，当前页用橙色标记；不绘制假的微信胶囊。
- 首页：品牌工具栏 → 主题主视觉（约 210px）→ 8 项内容入口（观赛、报名、榜单、视频、球员、球队、球场、服务）→ 真实公开赛事 → 同城服务 → 本人入口。没有赛程/比分数据不新增虚构“今日比分”；素材照片标明示意。
- 赛事：紧凑标题与说明 → 进行中/即将开始/历史筛选 → 真实赛事卡 → 报名及观赛链接 → 私有赛事/最近观看。移除重复巨幅通用海报，首屏尽快见内容。
- 同城：紧凑城市服务介绍 → 四种消费入口 → 真实供给卡 → 地图/筛选/扩展服务。距离、已审核、可预约均绑定现有真实状态；不添加假价格、假距离或假供给。
- 球队：清楚区分我的球队与公开查找；未登录用有品牌感的登录卡与公开入口；已登录使用真实球队卡、角色、报名入口；创建/加入遵循原授权。
- 我的：未登录突出登录价值与微信状态，保留邮箱/找回/协议；已登录本人资料 + 四个快捷项 + 常用服务；角色工作台条件不变，更多服务折叠。微信 disabled/unknown/loading/unbound/error 分开。
- 二级页面：沿用现有结构，通过共享表单、卡片、页头、状态卡与按钮统一视觉。交易条款、确认步骤、恢复入口不删除、不默认同意。

4. 静态兼容渲染、官方微信运行时、真机分开报告。当前云端不能操作用户 Windows，本机验收仍需在 `D:\Projects\small-city-basketball\apps\wechat` 执行。
