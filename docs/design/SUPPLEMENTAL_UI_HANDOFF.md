# 六项补充功能：UI交接与Codex执行提示词

状态：UI需求与交互蓝图完成；后续UI001已交付[可编辑视觉初稿及预设关键原型](WECHAT_UI_V2.md)，详见[画板/角色/状态清单](UI001_SCREEN_INDEX.md)。前端实现、真实API/外部联调与微信真机仍待交付。本页不计入现有68条原生路由或历史Figma画板。业务依据：[总设计](REMAINING_SIX_FEATURES.md)及其中六份专项；现有风格依据：[UI_SPEC](../UI_SPEC.md)。

## 1. 导航、视觉与公共组件

保留小程序“首页／赛事／同城／球队／我的”。地图、撮合、培训由同城进入；球队约赛也从球队入口进入；保险从报名／订单进入；工作人员在我的工作台接收派单；广告与结算在有权机构/运营后台。普通用户不出现财务配置、审核与调度按钮。

沿用最新全国化设计：深蓝 `#123C73`、强调橙 `#F28C28`、背景 `#F4F6FA`、正文 `#18283F`。优先已有组件与设计token，避免使用历史旧色值覆盖最新版。橙色承载主要动作、深蓝承载标题和结构，状态同时有文字/图标，不单靠颜色。金额使用等宽数字且保留币种，时间显示明确日期和时区，不把缺失费用显示为0。

手机以390宽绘制，验320/430和底部安全区；后台以1440宽绘制，验1024和必要的390只读/审批流程。基础间距4/8/12/16/24/32；内容密度与现有页面一致。表单文字至少16px、主要触控区至少44px；标题正文层级、可见焦点、读屏标签与错误关联统一。少量动效只解释状态变化，支持减少动画。

新增公共组件：范围标签、供给卡与匹配理由、分项报价卡、版本变化提示、截止时间、待核对状态条、步骤进度、授权摘要、资格阻塞清单、费用/退款明细、审计时间线。所有业务操作反馈需能对应服务端状态；“已受理”“已付款”“已承保”“已履约”“已结算”分别表达。

## 2. 页面蓝图（逻辑页面，不是现有路由）

| 模块 | 必画页面 | 关键区块／主动作 | 关键异常 |
|---|---|---|---|
| 保险 | 产品及条款；投保资料确认；投保/保单详情；退保进度；后台供应商与对账 | 按批准销售模式呈现服务方跳转或获准的数据提交；主体/范围、必要授权、费用、条款与保障起止；查询原单、查看保单 | 主体未确定先画关闭态和跳转分支；资料不足、未成年人缺授权、UNKNOWN、拒保、退保受限；不得直接显示投保成功 |
| 地图 | 同城地图/列表；跨城范围确认；选中服务卡 | 筛选、地图、搜索此区域、范围标签、结果面板；搜索/恢复上次范围 | 拖动未搜索、搜索中再拖动、无供给、超范围、地图失败；详见MAP01—08 |
| 撮合 | 类型与需求；公开范围审阅；候选结果/比较；意向详情；我的需求 | 实际地点/时段、预算、匹配理由/证据覆盖、通知范围；生成候选、发意向、进入原预约 | 权限不足、未知报价、资格/档期变化、撤回/过期、无候选 |
| 派单 | 客户需求；客户报价确认；工作人员邀请详情；进行中/履约；运营调度 | 服务/交通/住宿/平台费、时段与缓冲、批次、报价锁和剩余时间；报价/确认/拒绝/查看履约 | 锁过期、另人已承接、客户改价、支付待核对、无人接单、跨城条件不满足 |
| 培训 | 课程列表；课程/班次详情；报名与授权；我的课程/课次；签到交接；请假补课/退费；机构排课/招生 | 课程目标、年龄段、资质、容量、课程表、学员/付款人、合同和课次价格；选择班次、报名、签到、申请退费 | 候补、满员、晚付款、监护撤销、课程变更、停课、出勤争议；未成年人信息不公开 |
| 广告分成 | 合同/分成协议；收款与履约证据；结算预览；审核/执行详情；收款方对账 | 合同版本、可分配基数、参与方、扣减/尾差、退款/追回、外部状态；生成预览、独立审核、执行/核对 | 无真实收款、协议缺签、金额不守恒、商户不支持、UNKNOWN、回退失败/不足额 |

每页至少给出：用户/角色、入口、首屏信息优先级、字段与校验、主次操作、返回路径、加载/空/失败/无权限/过期状态、对应需求段落。流程较长时分步骤，费用/对象/时间的最终确认必须集中呈现。后台宽表在窄屏改卡片或可访问横向阅读，不能隐藏关键信息。

## 3. 关键路径原型

必须能逐步点通：地图拖动→搜索→查看服务；发布需求→候选→意向→原预约确认；跨城邀约→工作人员报价→客户确认→真实订单状态；培训选班→名额锁→付款待核对→课程表→请假/退费；保险按批准模式跳转服务方或提交获准资料→待核对→已出单/拒保，未选模式时另画关闭态；广告协议→收款→结算预览→独立审核→分账待核对。

另做失败分支：定位拒绝仍浏览；地图旧请求丢弃；候选失效；两位工作人员同时承接；名额到期后支付成功；保单结果未知；已分账后退款。原型使用合成姓名/机构和明确演示金额，无真实身份证、手机号、保单或支付凭据。退款进度和业务取消分别表达，不把关闭页面视为取消。
