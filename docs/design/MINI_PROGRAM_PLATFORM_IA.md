## 页面结构

| 页面 | 结构（自上而下） | 角色与权限 |
|---|---|---|
| 首页 `home` | 品牌头图、口号、“看赛事”主按钮 → **我的赛事**（最多3条进行中/即将开赛，“全部赛事”）→ 赛事观赛/我的球队/赛事数据/比赛视频 四宫格 → **扩展服务·按位置找球员**、查看我的预约、进入本人球员中心 | 未登录：登录卡+打开观赛链接；无机构身份：说明卡，引导我的球队/公开链接 |
| 赛事 `watch` | 介绍 → **我的赛事**（进行中/即将开赛/已结束/筹备中/已取消分组）→ 打开一届赛事（观赛链接）→ 公开赛事目录（C18：进行中/即将开始/历史，城市筛选，分页；此前为“未开放说明”）| 只对 `session.organizations` 中的机构读取；服务端：管理员见全部，其他工作人员仅见被分配赛事；某机构403只显示该机构失败，不影响其他机构 |
| 赛事详情 `org-event` | 赛事卡（状态/日期/场地/赛制）→ 页签：**赛程**｜**积分排名**或**分组与淘汰**｜**球员数据** → 刷新 | 进入需 orgId+eventId（UUID）；401/403/404清空页面并显示“无法查看该赛事”；单页签403/409只影响本页签 |
| 公开赛事 `event`／单场 `match` | 不变：观赛键进入，赛程、排名/晋级、媒体、单场比分 | 匿名只读；撤销即清空 |

## 状态与文案

- 赛事状态：草稿→“赛事筹备中”，报名开放/关闭，赛程已发布，比赛进行中，本届已完赛，历史赛事，已取消（`api.eventStatus`）。比赛状态沿用 `api.matchStatus`（待开始/进行中/暂停/已结束/取消/延期）。
- 积分：`DRAFT_PREVIEW` 标“积分规则尚未锁定·草稿预览”；`PUBLISHED` 标“正式积分·仅计入独立确认的赛果”；`RESULT_SOURCE_INVALID` 不显示任何榜单，提示“正式赛果来源待核对”。
- 球员数据：只显示得分、犯规、名单场次；固定说明“篮板、助攻、抢断、盖帽、失误、命中率与上场时间：未统计”，“名单场次”不代表实际上场；展示覆盖、未归属和待确认场次。
- 加载、空数据、错误、无权限、未登录均有独立文案；不显示示例比分或补0。

## 交互

- 首页/赛事页 `onShow` 读取会话后串行读取各机构赛事（每机构最多50条）；会话版本变化或页面卸载后迟到响应丢弃，不显示上一账号的私有列表。
- 点击赛事卡进入 `org-event?orgId&eventId`；入口参数先做UUID校验。
- 积分页签存在有效公开发布时提供“打开公开观赛页”。
- 底栏仍用 redirectTo 切换四个主页面。
