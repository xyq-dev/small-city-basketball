## 五、不可改变的交互与业务边界

- 五导航固定为：首页／赛事／同城／球队／我的。普通观众不直接看到无权工作台；角色标签不构成权限，仍以每次 API capability 和资源归属核验。
- **微信优先是入口优先，不是自动开户。** 当前微信登录仅支持已经绑定的应用账号：复用挑战、`wx.login`、服务端登录和会话核验；不得按昵称自动合并身份、静默创建账号或跳过明确同意。
- 微信未配置、能力读取失败、正在登录、未绑定、拒绝/失败、成功后返回原操作须区分。未配置时微信入口可见但禁用，并提供已有账号登录；能力未知不能写成确定关闭。未绑定用户先登录已有账号，再按既有重新认证与明确同意流程绑定。
- 保留邮箱/账号登录、找回、会话失效、切换账号、解绑和注销入口；清除敏感输入及旧身份相关临时状态，不重放上一账号请求。未勾选的必要同意不能默认勾选，不能凭前端动画直接进入“已登录”。
- 同城“查看档期”进入本页供给详情状态；提交预约只有收到确定成功回执才进入原预约，未知回执沿原请求核对。
- 本人球员中心“收到的预约”保留 `view=received`，逐场详情也保留视角，不能落入默认“我发出的”列表。
- 平台服务资料审核是 platform 本页审核面板；城市授权/评价处理保留 `mode=platform` 和真实平台权限检查，不能误连普通城市个人页或本人打分页。
- 订单入口必须携带真实上下文，缺少原订单时显示选择/恢复入口，不凭空创建资金单；付款、退款、分账回退、履约和独立批准分别展示。
- 报名资料、外购保单、资格预审、监护确认与最终报名审核保持独立。在线保险、微信通知、正式支付/分账、直播通道按当前能力开放；UI完成不能把关闭态改成已开通。
- 本地离线草稿不是服务器已接受的比分；时钟/换人/节次按现有离线限制。比赛结束仍需独立赛果确认。
- 私有资料、公开档案、宣传、直播/录像用途分别授权；未采集统计显示“未统计”。设计人物、队名、日期、比分和金额仅用于合成演示。
