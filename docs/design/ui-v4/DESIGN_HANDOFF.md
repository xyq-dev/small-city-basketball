## 交付范围

73条现有原生小程序路由主视图、15账号状态、6角色分支、12通用状态、10个320/430关键适配画板，共116张。统一原型页另放106屏副本和1个评审目录，含943个连接（包括返回），16个起点；不是新增106条业务路由。

所有界面由可编辑文字、原生图层、组件实例与独立图片组成，未用整屏位图替代界面。颜色、字体和基础组件复用V4设计系统。源位图只在参考素材目录保留。

## 如何使用

1. 把 CURSOR_UI_V4_PROMPT.md 全文交给Cursor，连同本包一起打开。
2. ROUTE_INDEX.csv 提供116个画板的原生路由、同路由query/状态、角色、节点与链接。state-*是通用设计状态，不是实际新增route；320/430是关键适配参考。
3. 先完成“我的”双态和共享壳层，再按设计分组连续补齐全部73路由；保留本地未提交及PR38/39已有成果。
4. 可编辑Figma为视觉定稿依据；REFERENCE_V3只为追溯。图中演示日期、比分、金额与人物不得写成线上常量。

## 关键修订

- 微信优先入口，仍保留未开放、能力未知、未绑定、失败及邮箱登录。现有后端仅支持已绑定应用账号，不因UI改动静默开户。
- 同城档期进入同页详情；收到的预约使用view=received；平台权限和评价审核使用mode=platform与真实权限。
- 无关联原资金订单时禁用入口，不让条件意向自动产生收费单。
- 记分离线提示前置、加分双列、比分对齐；离线草稿与权威比分、记分结束与正式赛果分别处理。
- 修复长标题孤字、统计卡高度和蓝色提示卡底色；116个设计/状态画板完成数量核对，各模块与关键状态完成分组视觉审阅，320/430关键布局通过结构检查。
