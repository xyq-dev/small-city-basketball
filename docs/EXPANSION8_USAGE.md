# 八项扩展使用与验收路径

本指南对应扩展分支的源码入口，当前合并、测试和正式环境状态以[当前状态](CURRENT_STATUS.md)为准。外部服务是否开放由实际账户准入、服务端配置和当前权限决定；看到入口不等于已经开通支付、保险或直播。配置与恢复要求见[运行边界](EXPANSION8_OPERATIONS.md)。

| 功能 | 入口 | 使用顺序 |
| --- | --- | --- |
| 全国统一搜索 | 首页顶部搜索按钮 | 输入名称，按赛事、球队、球员和地区筛选；只显示当前允许公开的来源，继续分页不会跳过未检查的结果 |
| 微信通知与站内消息 | 我的 → 我的消息、微信订阅提醒 | 先绑定当前微信身份，再逐次选择需要的提醒；在站内核对开赛、改期和报名审核消息，可撤销后续订阅 |
| 报名费、保证金与服务资金 | 我的 → 对应机构的收款条款与资金管理；具体报名或预约的资金订单 | 管理方发布条款并独立批准；创建来源前本人明确同意；付款后查询渠道确认记录，审核、冻结及履约继续独立核验 |
| 直接开播与多平台分发 | 单场比赛管理 → 开播、分发与录像 | 选择已核验频道、最长时长、费用上限和是否录制，创建待批准直播；独立管理者填写依据并批准，再由另一名有权人员显式开始采集 |
| 整场录像、转码与集锦 | 本场直播工作台 → 查看录像与媒体作业 | 查看实际录制产物；核对源PTS与时间偏移后申请转码或按有效得分生成集锦，再按当前内容权利独立公开或撤回 |
| 在线保险 | 本人资料 → 保险购买、查单与退保进度；我的 → 本人保险订单 | 先完成独立资格预审，再选择有效报价并投保；外部付款、出单、保障有效和最终报名审核分别核验，查单及退保沿用原订单 |
| 青少年与监护确认 | 我的 → 青少年与监护确认；赛事管理 → 青少年与监护独立审核 | 先取得必要资料处理同意，再提交本人资料和资格预审，分别完成本人、监护人和机构的独立确认；公开用途保持可选 |
| 自助注销 | 我的 → 账号自助注销 | 核对未完成事项，以当前密码明确申请；先处理未决资金、保险、履约、停流和机构负责人转移，等待期内可明确撤销 |

## 资金操作

报名费与保证金是两项独立条款。球场、人员、球员服务同样在真实来源创建时绑定服务器报价；页面金额、实际收款方和条款均需本人核对。旧来源没有收费绑定时，不因后来发布条款而追收。

客户端支付完成提示不能代替服务器的渠道确认。原付款、退款、分账或回退结果未知时，应使用原编号查询，不能另开一笔来消除未知状态。退款、扣减及分账由符合条件的独立人员复核；已有退款占用会继续阻止需要足额资金的名单冻结或履约。

## 直播和媒体

开始前需要当前人员权限、两侧参赛者的当前内容权利，以及云入口和外站账号准入。页面显示转推已连接后，仍需在外站核对实际画面。切到后台会停止本机采集并申请暂停；恢复采集是显式操作。

停止未知表示尚未取得物理停流证据，频道占用会保留。刷新页面不会恢复推流，也不能据此认定已停止计费。录像独立于各个转推频道；中断产物可能只是部分片段，实际时长不等于整场完整。

集锦使用有效在线得分事件与人工核对的源PTS，补录事件不会被推造为录像时间。公开、私有下载和派生产物持续复核原始内容授权；撤回原始录像也会阻止其派生产物继续访问。数据库备份不含MP4字节，媒体归档需单独办理。

## 保险与青年流程

已有有效外部保单仍可走本人资料中的上传和人工审核，无需重复购买。在线保险供应商尚未选定，实际adapter尚未接入，因此购买编排默认关闭；资格预审和既有外部保单流程仍可独立办理。

监护邀请只先收集别名和监护账号编号；账号编号可由对方在“我的”复制。取得必要处理同意前不要上传身份、照片或家庭证明。确认数据处理不等于监护关系已核验，也不等于已通过最终报名。

参赛、宣传照片、公开档案、直播录像分别确认。拒绝可选公开用途不单独取消参赛资格。原监护同意撤回或监护账号关闭后，已成年本人可在同页核对当前材料，依据服务端独立年龄证据重新确认资料处理；页面不能通过填写年龄绕过核验。资料再同意不会恢复旧公开许可。

## 注销与未知结果

注销保留必要的交易、赛果与审计历史，不承诺删除已经转发或下载到外部的内容。未决原订单、未确认停流及实际履约问题需要先处理；负责人应先转移机构责任。可选延期不代替这些业务检查。

任何页面显示“原操作结果待核对”时，先读取原回执或当前服务器记录。移除本机恢复标记只影响本机，不会取消服务器原操作，也不能用来绕过未知结果或版本冲突。
