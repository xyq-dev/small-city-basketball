# 小程序产品定位与功能完整度审计（C13）

2026-10-26 Asia/Shanghai；C13；分支 `feat/mini-program-platform-alignment`，基线 `a4d61a5`（含WXML运算符编译修复，未合并main）。

## 结论

- **偏离原因**：C11六屏是球员预约模块的确认稿，却被当作整个小程序的首页与信息层级。首页主按钮为“找球员”、第一区块“按位置找球员”、引导为“选球员→填比赛→确认到场”，赛事只有一张“赛事观赛”卡片（`apps/wechat/pages/home/index.wxml`，C11/C09）。底栏“赛事”只是粘贴43位观赛编号的输入框，没有赛事列表（`apps/wechat/pages/watch/index.js`）。
- **后端能力与小程序脱节**：机构赛事列表/详情、赛程、积分、分组/淘汰、本届个人基础数据、生命周期在API中已存在（C02–C05），小程序只接入了公开观赛键入口、球队报名和预约。
- **本轮修正**：首页改为赛事优先；“赛事”页增加“我的赛事”（仅当前账号机构身份可读的赛事，服务端仍按角色过滤）；新增原生只读“赛事详情”（赛程/积分或分组淘汰/球员数据）；球员预约整体保留并移入首页“扩展服务”。公开赛事目录需新增后端发布规则，另写设计交审（见[公开赛事目录方案](../design/PUBLIC_EVENT_DIRECTORY.md)）。
- 本审计不是小球迷一比一验收。小球迷仅有App Store介绍可核验（见下文），其页面层级和交互未实测。

## 判定口径

| 类别 | 含义 |
|---|---|
| A 后端已有，小程序未呈现 | API与权限已在main，小程序没有入口或页面 |
| B 页面存在，入口/层级/流程有问题 | 页面可用，但入口隐藏、优先级不当或断流 |
| C 仅设计/占位/合成数据 | 只有Figma稿、规划页或测试fixture |
| D 缺少真实后端能力 | 需要新业务规则/数据/API |
| E 竞品资料不足 | 小球迷对应功能无可核验资料 |

## 小球迷资料现状及缺口

可核验：开发者[App Store介绍](https://apps.apple.com/cn/app/%E5%B0%8F%E7%90%83%E8%BF%B7/id1552855898)（2026-10-23查询，见COMMERCIAL_PRODUCT_PLAN）列出联赛管理、赛程生成、球队与比赛记录、比赛管理、视频直播与互动。

缺少、需要提供的资料（截图或官方页面）：首页与底部导航；赛事列表/搜索；赛事详情；赛程、分组与对阵；即时比分与比赛详情；积分与数据榜；球队页；球员页；个人中心与主办方/记录台入口；直播/回放页。在获得资料前，本项目导航沿用UI_SPEC已确认的“首页／赛事／视频／我的”，不宣称其为小球迷原版。
