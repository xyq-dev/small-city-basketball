## 验收标准

- **列入权限与条件**：
  - 开启公开观赛不自动列入；
  - 只有机构 OWNER/ADMIN 或该届有效 EVENT_MANAGER 可以 LIST/UNLIST；
  - LIST 要求机构 ACTIVE、存在同机构同赛事的当前未撤销公开授权，且赛事状态与授权用途一致。
- **命令要求**：4–500 字原因、`expectedEventVersion` CAS，同事务推进版本并写审计；失败无部分写入。
- **分组**：LIVE / UPCOMING / HISTORY 只按状态与用途推导。HISTORY 的列入与合法 UNLIST 不因赛事已关闭而被拒；ARCHIVE 保留 HISTORY。
- **撤出**：
  - UNLIST 只撤目录，分享链接仍有效；
  - 公开授权撤销（DISABLE、完赛、重新开放、发布新轮次、隔离批次）与机构停用，同事务撤出；
  - 撤出后不自动恢复。
- **匿名接口**：
  - 白名单字段、`no-store`，不读取、不设置 Cookie；
  - 键集分页，limit 默认 20、最大 50；游标与筛选绑定，篡改返回 400；
  - 同 IP 每分钟 60 次。
- **小程序**：
  - 匿名请求无 Cookie，不影响登录；
  - 空列表、分页失败保留已读条目、筛选竞态、刷新移除旧条目；
  - 列入 / 撤出的迟到确认零写请求。
- **验证**：
  - 真实 PG/API 测试、小程序测试、改动页面布局检查；
  - 真实 API 小程序流程；
  - typecheck、格式、`git diff --check`；
  - 最终 HEAD 的 CI 已核对。
