主办方能在演示环境中完成“查看工作总览→查看赛事列表→创建草稿→进入详情→编辑草稿”。让页面流程可运行，为后续真实 API 保留替换入口。

## 最小页面与字段

1. 工作总览：示例赛事、待办、今日比赛；未接通的菜单有明确占位说明，不使用失效按钮假装可操作。
2. 赛事列表：列表/空状态、名称或状态筛选、进入创建与详情。
3. 创建赛事：`name`、`startDate`、`endDate`、`timezone`（默认 `Asia/Shanghai`）、可选`venueName`、`format`；必填和开始/结束日期校验。
4. 赛事详情：展示草稿资料，允许编辑与返回列表；创建仅生成 `DRAFT`。`format` 使用 `ROUND_ROBIN / GROUP_KNOCKOUT / SINGLE_ELIMINATION`。

P01 不实现发布与报名状态流转。Mock 通过统一服务入口使用；默认内存保存，页面清楚提示“本次演示数据，刷新重置”，禁止静默采集真实人员资料。
