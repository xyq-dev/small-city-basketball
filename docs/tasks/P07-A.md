## 集中配置与注册

production显式HTTPS APP_ORIGIN，拒绝userinfo/path/query或错误Origin；HOST容器设0.0.0.0，开发默认127.0.0.1。PORT须严格合法整数。DB secret只从明确环境／*_FILE读取，二者同时配置拒绝，错误不得打印URL、password、input或cause；API只挂runtime凭据，一次性job才挂admin/migrator/restore凭据。

机构注册与participant注册独立开关，production默认均false，dev/test保留既有true；默认解析必须在createApi/服务路径也生效，不能仅main。生产Compose显式organization=false、participant=true，保障新领队可先注册再获既有邀请；没有邮件投递／邮箱验证则如实说明。新增GET /v1/auth/capabilities只返回两个布尔，Auth UI按服务配置展示注册入口，失败不猜开放状态；普通登录始终可用，overlay/watch独立入口不因此发私人请求。

TRUST_PROXY_HOPS只支持0或1，开发默认0；本包私有单跳Web→API显式1，禁止trust proxy=true/任意hop。Web覆盖外来X-Forwarded-For／Host／Proto，API与PG不暴露host端口；保持20次／小时注册限制和原精确Origin。验证伪造header不能换IP逃限流，不让所有用户无意共用代理地址。

## 首位机构负责人

## 数据库身份及就绪

初始化管理员仅建DB／roles，migrator拥有DDL及btree_gist，runtime无superuser/CREATEDB/CREATEROLE/replication/bypassrls/表owner/owner成员关系/TRIGGER/TRUNCATE/schema CREATE/TEMP。官方镜像POSTGRES_USER创建的是superuser，不能用作API身份。

固定受审计权限manifest按现表/查询声明SELECT、必要INSERT/UPDATE，DELETE仅auth_rate_limits。FOR SHARE/FOR UPDATE也需至少一列UPDATE权限，overlay_sessions等不可变表授锁列UPDATE(id)后仍由不可变触发器拒绝实际改写；不能只搜索UPDATE语句推导ACL。schema_migrations只读。001–006无sequence，不能泛授未来对象或sequence。迁移／恢复后显式重应用同manifest并验证；权限不足或高权runtime拒绝就绪。

保留现health连接检查；新增readiness精确核验预期迁移文件名／checksum完整集合、btree_gist、当前角色和必要权限，缺失／漂移／extra migration／危险角色给固定503，不泄漏SQL／role／URL。生产启动校验不执行迁移或seed；Compose等待显式migrate job成功后启动API，健康检查用readiness。SIGTERM正常关闭HTTP与Pool，compiled运行无需tsx/Vite。

## 备份及恢复隔离

PG18 pg_dump完整custom archive，输出私有文件/0600，源只读，不上传原dump或secret到CI artifact；连接凭据不进argv/日志。恢复目标必须新建空隔离DB／卷，校验明确自有资源，禁止覆盖源或任意已有DB。先建角色/owner，再完整pg_restore fail-fast／single-transaction、明确no-owner/no-acl后重应用受审计manifest；不先migrate再data-only，不禁用历史守卫做应用层恢复。

CI夹具完成后停止／隔离全部源写者，关闭对外API写入且没有背景写任务，在同一静止区间采集业务／39表基线并完成dump；dump结束前不允许其它提交。首卡不实现导出MVCC snapshot／PITR。生产pg_dump自身一致不代表独立晚取的baseline与dump同一时点，不声称RPO零或不停机恢复保证。

第一阶段比较39表、所有schema/checksum、冻结名单、正式赛程／预约、原始clock/fence、确认历史／收据、排名sourceHash、活跃／撤销public及OverlayGrant/session等全量指纹／业务快照，证明恢复等于备份点。重启检查不能替代本阶段。

第二阶段单独恢复隔离事务：新DISABLED、无可登录凭据的系统主体代表维护CLI，不冒用原owner；password_hash使用符合001长度80–256且不匹配scrypt格式的不可验证哨兵，不存NULL／空串或生成可用密码；该主体不获org membership，public.revoked_by／audit.actor_id的users FK由新记录满足；保留明确审计。撤销所有旧private sessions、pending invitations；public仅revoked_at IS NULL记录设置revoked_by为新系统UserId及revoked_at，overlay仅v1未撤销→v2+revoked_at+非空trim理由，跳过所有已撤销历史，不进行第二次更新。overlay_sessions不UPDATE/DELETE，靠grant终止读取；旧lease仅将有lease_id且尚未到期的行提前expires_at，保留leaseId/holder/client/fence；空初始租约的身份／expires均NULL且fence0，必须跳过，不能破坏004 CHECK。状态变更遵从现不可变／版本约束并touch涉及Event版本，不能破坏Match/state/result历史。所有organizations置DISABLED（沿001现有ACTIVE/DISABLED枚举，不新增状态）形成隔离闸；旧team grants/org memberships/event/match staff可能反映过时授权，不能因重登录恢复可用。

首卡恢复终点为“隔离恢复已验证、旧凭据失效”。重新开放须外部当前授权清单人工/manifest核对及明确运维操作，不由旧dump推断当前权限、不自动切流。只可证明后续fence大于备份点，不能声称超过备份后丢失的未知最大fence。恢复隔离后的预期变化与第一阶段一致性分别验收，不把全库指纹仍相等作为隔离成功条件。

## 首卡冻结的打包接口

固定角色scb_admin（仅初始化）、scb_migrator（DDL owner）、scb_runtime（日常）、scb_backup（只读dump）；默认应用DB scb，CI使用唯一隔离名，恢复目标必须scb_restore_*且全新空库。权限manifest路径packages/contracts/runtime-privileges.json，由PG负责人独占新文件，API只读消费；schema_migrations只读、backup只授SELECT及schema USAGE／DB CONNECT，不授行锁UPDATE或DDL。

API compiled入口apps/api/dist/main.js，迁移apps/api/dist/database/migrate.js（API负责人补*_FILE读取），owner apps/api/dist/bootstrap-owner.js；readiness固定GET /ready，保留GET /health。PG作业Node入口ops/db/provision.mjs、ops/db/migrate-and-grant.mjs、ops/recovery/backup.mjs、ops/recovery/restore.mjs、ops/recovery/quarantine.mjs，由PG负责人独占。migrate-and-grant只串行执行compiled migration及manifest，不在API启动自动运行。backup／restore用PG18客户端，PG负责人脚本不含Docker全局清理；rootCI仅操作本run/project创建的资源。正式API函数签名／DTO首提交统一分发，不让不同AI发明接口。

Docker targets固定api、web、db-tools。api用Node24.22.1-bookworm-slim，USER10001:10001；web用nginx1.30.6-alpine，USER101:101／8443；db-tools用PG18.6-alpine3.24加官方Node24.22.1-alpine3.24同架构Node二进制及必需libstdc++，USER10001，含pg客户端、pg JS依赖、实际ops脚本与必要compiled入口。CI必须实际证明node --version、pg_dump --version、pg/contract imports和compiled入口可运行，不能以COPY静态正确代替。若二进制依赖存在真实不兼容，打包负责人提出最小替代并经root同步，不能静默改主版本。

服务postgres→provision→migrate→api→web，bootstrap-owner/backup/restore/quarantine只在ops profile显式运行；只有Web发布host端口。镜像必须COPY ops、manifest、SQL、contracts实际目标，且不带原始host源码、开发依赖或secret。Webentrypoint只解析受限https origin的authority，envsubst仅替换该已校验authority变量，保留nginx $remote_addr/$uri等变量；明确覆盖Host/Forwarded-Host/Proto与XFF，不能用proxy_add_x_forwarded_for拼不可信链。

统一secret目标：/run/secrets/database_runtime_url、database_admin_url、database_migrator_url、database_backup_url、database_restore_url、bootstrap_owner_input、tls_certificate、tls_private_key。只挂对应job，API永不读高权URL。所有*_FILE与同名inline同时存在拒绝。

Compose file-backed secrets保持宿主inode UID/权限，不能靠uid/gid/mode长语法改变它。宿主secret父目录0700，API／ops所需文件0400且owner10001:10001，Web cert/key owner101:101且0400；PG初始化密码仅其root entrypoint读，文件root:root0400；私有archive目录owner10001:10001、0700，dump0600。提供明确安装／chown说明并在CI实际检验可读和互不挂载，不能把权限失败改成API root或所有secret公共可读。
