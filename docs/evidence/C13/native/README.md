## 新图标390宽检查结论

- 底部导航四页同一套线性图标：选中橙色、未选中灰色，无圆点；首页、赛事选中状态在截图中准确。
- 首页四入口：篮球场、多人、柱状统计图、播放框；五个位置为球衣轮廓＋PG/SG/SF/PF/C，标签放大后清晰，中文标签保留。
- 返回、搜索、定位、日期、时钟、提示、审核盾牌、对话、更多、勾选/加号、下拉箭头均为同一套图标，大小与对齐一致；无缺图、拉伸或模糊。
- 本轮另修正：球员选择按钮隐藏的184px点击区域（覆盖姓名区）收回到44px；筛选与选择器中的“⌄”字符改为图标。

## 旧图标390宽检查结论

- 无横向溢出或裁切；长球队名、长赛事名在卡片与表格内换行，按钮文案完整。
- 创建预约卡片、比较表、返回箭头、订单卡按钮均正常（此前问题已修复，见 [C13交接](../../../handoffs/C13.md)）。
- 底部导航四页统一为图标样式；安全区底部留白正常。
- 未登录、无机构、无权限、空数据状态均有明确文案与入口。
- 首页扩展服务区（五个位置、我的预约、球员中心、说明）在下滑图中完整可见。
- 已知且保留：通过reLaunch打开的非首个页面左上出现微信自带“返回首页”按钮；球员数据表头“名单场次”在390宽较紧。
