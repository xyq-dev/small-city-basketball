## 本次完成（均为既有已批准 API 的客户端接入）

### 比赛媒体：补齐 Web 已有的 C05 能力（match-media）

- **受信外链草稿**：
  - 只在服务器返回 `trustedExternalHosts` 时出现；
  - 本地按服务器同样规则检查：须为 HTTPS，主机在列表内，不带端口、账号或片段；服务器仍是最终判定；
  - 沿用草稿的“先存后发、未知结果安全保留”保护。
- **视频时间标记**：
  - 只用于已有独立确认赛果的私有视频草稿；
  - 选择确认范围内的比赛记录，填写名称和以秒计的起止（最多三位小数）；
  - 提交固定媒体版本与确认 ID。重复提交会因版本冲突被服务器拒绝，所以未知结果重新读取即可。
- **撤销后清除内容**：
  - 只对已撤销的文件开放，需 4–500 字原因，并在确认框写明“不可恢复”；
  - 做 CAS；审计由服务端完成；
  - 不提供自动清除。
- **私有预览**：
  - 下载比赛私有文件到临时文件，先核对类型与字节数是否与记录一致；
  - 图片用 `previewImage`，MP4 在页内播放；
  - 关闭、页面隐藏、卸载、账号变化时立即删除临时文件；
  - `download()` 只按精确路径额外放行比赛媒体内容（图片与 MP4）。
