## 1. 统一视觉与导航

品牌固定为「小城市篮球」，宣传语「小城市，也有大主场。」。主色 `#132C49`，强调色 `#FF6B2D`，背景 `#F5F7FA`；颜色同时配合文字和图标表达状态。分数、计时和当前操作对象优先级最高，后台以任务和可操作信息为主。

四组图片是概念参考。实施需统一队徽、球员名称、赛事日期、比分与状态，不能逐图照搬互相矛盾的数据。生产页面不得出现示例人物的身份证或真实联系方式。

小程序底栏：**首页／赛事／视频／我的**；领队从“我的球队”进入管理。机构后台、平台运营和现场工作台使用独立角色导航。尚未开放的功能注明“规划中”或隐藏，不能保留点击无反馈的伪功能按钮。

### 创建与编辑字段

| 字段 | 规则 |
|---|---|
| `name` 赛事名称 | 必填，去首尾空格，1–80 字符；同名允许，依靠 ID 区分 |
| `startDate`／`endDate` | 必填日期；结束不得早于开始；原型不强制必须是未来日期 |
| `timezone` | 默认 `Asia/Shanghai`，P01 固定展示；后续多时区由后端支持 |
| `venueName` | P01 可选，最多 100 字符；空值显示“待定”，不伪装成已预订场地 |
| `format` 赛制 | 必选：循环赛、分组后淘汰、单淘汰；仅作为草稿配置，不表示原型可生成赛程 |

赛制字段机器值由统一数据/API 契约管理；不得在多处自行翻译成不同枚举。新建仅产生 `DRAFT` 草稿。P01 默认使用内存演示数据，页面明确提示“刷新后重置”；如后续任务改用本地持久化，需同步调整说明与清除入口。

## 3. P02：真实API模式

P02新增注册／登录／退出、当前机构切换和会话恢复。API模式使用当前机构的真实赛事，创建后刷新仍可见；Mock模式仍保留演示标识及刷新重置提示，两种数据不能混用。

- 请求失效或退出后返回登录流程；机构切换隔离旧请求结果，不用上一个机构数据填充新机构页面。
- 创建入口按机构权限展示；详情编辑按服务端逐赛事 `permissions.canEditDraft` 判断，403／404／409提供明确反馈，最终写权限仍由后端核验。
- HTTP读取或后续分页失败时显示失败与重试，不静默退Mock或把部分列表当成功；保存失败保留输入。
- 邮箱账号不代表邮箱已验证，也没有微信登录、密码重置或平台运营页面。

- 工作人员按实际赛事分配查看报名、规则及审核动作；拒绝/退回展示原因，自审受后端阻止，不能仅靠隐藏按钮。关闭报名后不允许新建或提交DRAFT，只允许已有退回名单补交。
- 冻结操作展示获批队及排除数量，确认后保存不可变freeze并转只读；冻结不会发布赛程或显示“已排赛”。版本冲突提示重读，失败保留输入且不退Mock。

已完成桌面/手机Chromium的真实Web闭环，不代表微信小程序或真机验收。球员身份证、保险凭证上传、邮件验证、微信登录和OBS仍未接入；排赛新增范围见下节，不能把页面地图整体视为完成。

- “每场占用分钟”明确填写1–1440整数，“最少休息分钟”为0–43200整数，“最小日期间隔”为0–365整数。无间隔也需显式填0，不暗设放宽条件。场地窗口1–200个，同一场地窗口不能重叠；开始／结束时间及逐场输入明确为中国标准时间，不采用浏览器所在地时区。输入控件16px，主要触控目标至少44px。

- 检查只针对已保存版本；未分配、窗口／赛事日期越界、停用场地、场地／球队重叠、最少休息和日期间隔问题可定位到本方场次。外部占用不显示无权访问的赛事名称或名单。本地修改或准备重抽使原检查失效；取消重抽后也需重新检查旧稿。
- 动作由最新服务端capabilities决定。版本冲突保留输入并提示重读，任何分页后页失败都整体报错；API模式不退Mock。发布时新增的冲突会清除旧绿色通过状态，显示最新问题并阻止继续确认。
- 正式发布先显示球队数、轮数、场数、共享场地数、时间范围、占用／休息／日期间隔及只读后果；取消不提交。服务器发布事务再次检查最新占用；一次成功后隐藏编辑、重抽和重复发布入口。正式场次初始待开赛，不显示比分或假直播。

## 5. 所有页面的状态规范

| 状态 | 必须表现 |
|---|---|
| 加载 | 保留布局，给出正在读取的反馈；保存操作有独立状态，避免重复提交 |

| 搜索无结果 | 保留条件，提供清空筛选；不要误报为整个系统无赛事 |
| 失败 | 保留可恢复输入，说明失败动作，提供重试或返回；错误记录不带敏感资料 |
| 无权限／不存在 | 不回显受限资源详情；提供返回可访问列表的入口 |
| 只读 | 清楚说明原因，如已锁定、仅观赛或非主记分端；不能只把按钮变灰 |
| 离线／陈旧 | 显示同步状态及最近更新时间；未确认的操作不能显示“已保存到服务器” |
| 未开放 | 说明属于后续阶段，不伪造成功状态、直播画面、交易或通知送达 |

表单采用可读标签和就地错误提示；嵌套select及带初值textarea必须有显式稳定的可访问名称（如aria-label），名称不随选项或输入值变化，并用原生浏览器精确label验证；键盘可聚焦所有主要控件；手机主要触控目标建议不小于 44×44 逻辑像素。危险操作明确对象和后果，结束比赛与普通记分按钮保持距离。
