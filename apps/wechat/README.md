# 微信小程序源码入口（D01/D02原生页面）

原生无外部依赖项目，开发工具导入本目录。`touristappid`仅为可阅读的项目配置，不能调用真实微信登录或发布。实际启用须替换为已批准AppID，服务端配置同AppID/secret文件，并在微信后台配置basketball.playhubs.cn request/download合法域名、隐私说明与媒体域名。没有在本轮创建主体、凭据或付费资源。

公开入口只接受主办方原opaque观赛键，使用现有赛事/分页赛程/循环积分/分组晋级/淘汰签位/单场比分及服务器计时锚点/受控媒体API。不新增比赛状态、管理写入或自动公开目录；404撤销即清空页面。分享只含原公开授权；第三方公开外链只能复制地址并附不可撤回说明，不保证微信内播放。

账号页先用现有账号登录，再明确同意并重新验证密码绑定当前微信。未绑定不自动建号，不按昵称/unionid合并。wx.login临时code仅提交服务端；客户端无AppSecret，服务端不持久session_key或rawopenid。会话Cookie由wx.request响应显式提取，仅存模块内存并显式发送，不能把浏览器HttpOnly/Cookie jar语义当作小程序已验证行为。所有写请求发送固定Origin；未放宽服务端全局CSRF。关闭/重启进程不恢复会话，用户可用新微信code重新登录。

本机验证：`node --test apps/wechat/test/*.test.cjs`与JS语法检查。这里的wx.request为显式模拟transport；真实微信官方文档当前访问受限，Origin是否可在目标基础库发送、Cookie响应读取、合法域名、原生开发工具及微信真机/媒体行为全部待独立验收。未配置服务端时明确禁用微信认证，不是已上线小程序。


## 页面与主流程

按D01/D02高保真稿复用海军蓝/橙色、卡片、费用拆分及状态规范；99张业务/状态稿整合为21条动态原生路由，没有引入React/Tailwind或运行时依赖。

| 页面 | 路由 | 实现范围 |
|---|---|---|
| 首页 | home | 选人、预约、观赛、球队与球员中心入口 |
| 赛事入口 | watch | 仅接受主办方公开观赛键，无自动赛事目录 |
| 视频入口 | media | 从授权赛事进入单场已发布媒体 |

| 公开赛事 | event | 分页赛程、积分/分组/淘汰/名次与单场媒体入口 |
| 公开单场 | match | 实际比分、权威时钟、赛果、分节及已发布媒体 |
| 球员广场 | players | 已登录可见服务目录、位置/同价筛选与数据状态 |
| 球员详情 | player | 服务报价、档期、有限公开统计、样本及近期记录 |

| 球员中心 | player-center | 本人资料、审核状态、档期与报价 |

导入后从首页进入“球员广场”，未登录先进入账号并返回原页面。服务目录复用现有私有workspace，未伪造公开目录API。领队先选本人有权球队，再核对每个球员和逐场时间地点；服务费、平台费、交通与食宿分列，条件场报价与确定场分开。球员自行决定每场是否接受。预约不会自动加入赛事报名名单，报名资格和名单锁定仍由既有赛事流程判断。

## 数据、身份与恢复

- 数据仅来自当前有效授权、独立确认的现有个人得分/犯规记录；真实0、未统计、接口暂不可用分别呈现。不补造助攻、篮板、命中率、实际出场或实力总分。
- 会话变更立即清理私有视图，迟到响应拒收；异步操作固定账号、机构及资源版本。匿名统计请求不带账号Cookie。
- 创建和订单命令的待核对记录使用原commandId及不可变payload恢复；页面刷新/切换不自动新建重复命令，不把未知网络结果当作确定失败。记录损坏、存储不可用或安全随机能力不可用时明确停止相关写入。安全ID无Math.random降级。
- 资料声明默认未选中。上传材料不等于身份/保险核验通过，是否可提交以服务器当前能力为准。PDF/PNG/JPEG仅在现有8MiB限制内上传；查看私密文件下载后仅临时本地展示，隐藏/卸载清理。
- 实收、退款到账、分账为0，未接入真实个人撮合支付、自动通知或自动资格核验。现有预计平台费是报价快照，不能称作已赚收入。没有调用wx.requestPayment。

## 验证边界

执行`npm run test:wechat`检验真实Page/Component与工具函数的隔离VM、路径/权限/并发及恢复行为；`node scripts/preview-wechat.mjs --page=home --width=390 --out=/tmp/home.html`读取真实WXML/WXSS生成离线兼容HTML用于布局辅助，明确标为非微信运行时。兼容解析器不支持任意WXML第三方扩展，不替代官方编译器。

开发工具和真机应补验：目标基础库的安全随机API、显式Cookie/Origin语义、登录及合法域名、chooseMessageFile/文件预览与清理、scroll-view/固定底栏/安全区、媒体播放及真实弱网恢复。当前源码可交付不代表已通过这些目标环境验收，也未发布或部署生产。
