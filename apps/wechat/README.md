## 数据、身份与恢复

- 数据仅来自当前有效授权、独立确认的现有个人得分/犯规记录；真实0、未统计、接口暂不可用分别呈现。不补造助攻、篮板、命中率、实际出场或实力总分。
- 会话变更立即清理私有视图，迟到响应拒收；异步操作固定账号、机构及资源版本。确认弹窗、UUID 准备和发送前都检查原操作，已经发出而结果未知的请求保留原编号。匿名统计请求不带账号 Cookie。
- 新比赛媒体请求先把原编号、元数据和摘要保存后发送；回执 404 不代表可以换编号。大于 512 KiB 的文件分片上传，单文件仍限 8 MiB、会话24小时；显示“服务端已确认 X/Y 字节”，最终 FILE 回执才算成功。恢复时核对本地文件与服务端分片；旧 v1 未知记录继续人工核对。过期负载在请求路径内有界清理，另有 `node ops/db/media-cleanup.mjs` 显式维护入口，不宣称后台自动执行。
- 普通加入创建新成员，不按同名匹配历史成员。申请审批才授予新球队 TEAM_MANAGER，普通绑定不授管理权；退出/移除只改变长期名单，冻结报名保持原样。
- 私有赛季用途固定 PRIVATE_SEASON，账号绑定、主办方提名和 C07 同意都不能代替本人同意。授权撤销、绑定结束或提名人失权后旧授权不可复活；CLOSED 不冻结隐私撤销或重新确认的赛果。球员只读本人，机构榜只给 OWNER/ADMIN，未采集指标仍显示“未统计”。
- 创建和订单命令的待核对记录使用原commandId及不可变payload恢复；页面刷新/切换不自动新建重复命令，不把未知网络结果当作确定失败。读取原恢复记录异常时先安全重读，禁止以新编号覆盖；清除恢复标记前先展示最新记录并要求重新勾选核对。记录损坏、存储读取阻断或安全随机能力不可用时明确停止相关写入；已确认空记录但新写存储失败时仅保留当前进程的内存恢复并明确提示重启风险。安全ID无Math.random降级。
- 资料声明默认未选中。上传材料不等于身份/保险核验通过，是否可提交以服务器当前能力为准。PDF/PNG/JPEG仅在现有8MiB限制内上传；查看私密文件仅临时本地展示，隐藏/卸载时请求清理；媒体预览删除失败保留登记重试，下次启动/进入再清理，不承诺关闭瞬间必定删除。
- 实收、退款到账、分账为0，未接入真实个人撮合支付、自动通知或自动资格核验。现有预计平台费是报价快照，不能称作已赚收入。没有调用wx.requestPayment。
